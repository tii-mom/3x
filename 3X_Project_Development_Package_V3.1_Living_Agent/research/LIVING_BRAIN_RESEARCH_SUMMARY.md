# MaleCNS / Living Brain Research Summary for 3X

## 核心结论

MaleCNS 相关开源整活对 3X 的最大帮助不是“替代 LLM”，而是：

- 专门功能回路；
- sparse activation；
- 输入→内部活动→动作→结果 Replay；
- Skill 的可验证训练/认证；
- 把复杂 AI 变成用户看得懂的“它正在工作”。

## 项目启发

### DOOMFLY
学习实验和负结果透明：提醒 3X 不能把权重变化当“学习成功”。

### Stonkfly / TraderFly
市场输入映射与动作闭环有传播性，但没有证据证明真实果蝇 connectome 能稳定产生金融 Alpha；只借架构，不借结论。

### Flyhard
held-out evaluation / intervention 对 Skill Arena 很重要。

### Mario/Fly64
Eyes/Brain/Control 同步 Dashboard → 3X Brain Trace Replay。

### Fly Escape
消费级 UX 最有价值：用户改变环境，看一个生命体响应；复杂神经科学隐藏在底层。

## 3X Product Decision

Production：Semantic Agent Connectome。  
Labs：真实 MaleCNS Sandbox。  
Core Brand：Synthetic AI，不默认虫子。
