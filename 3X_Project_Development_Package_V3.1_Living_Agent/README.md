# 3X Project Development Package V3.1 — Living Agent / Implementation Ready

**This package supersedes V3.0 for all new development.**

Primary outputs:

- `3X_Project_Master_Development_Spec_V3.1_Living_Agent.md` — full continuous master spec.
- `00_AI_START_HERE.md` — first file for any AI coding agent or engineer.
- `AI_IMPLEMENTATION_CHECKLIST.md` — compact build checklist.
- `ai_studio/00_IMPLEMENTATION_MANIFEST.md` + numbered prompts — sequential AI Studio execution instructions.
- `schemas/` — DB, OpenAPI and event contracts.
- `configs/` — parameter status, feature flags and mock fixture.
- `simulation/` — economic model artifacts from V3.0/V1.1 plus V3.1 generation schedule.
- `research/` — Living Brain / MaleCNS product research summary.
- `ops/` — Testnet operational runbook.

## Intended workflow

1. Open/import the existing `yi-17-lab/3X` repository.
2. Create `feature/v3-1-living-agent`.
3. Provide this whole package to the AI coding tool.
4. Run prompts in `ai_studio/` sequentially.
5. Review and accept each Gate before moving to the next.
6. This package is implementation-ready for Demo/Testnet/Beta, **not an authorization for unreviewed Mainnet/TGE deployment**.
