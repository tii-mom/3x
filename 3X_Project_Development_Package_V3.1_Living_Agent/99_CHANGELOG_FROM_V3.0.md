# V3.0 → V3.1 Changelog

V3.1 保留 V3.0 的 Agent Halving、Proof of Agent Growth、Restricted Seed、Growth Vault、TON safety、Skill/Energy、Multi-AI、Beta-first 经济框架。

主要升级：

1. 开发策略明确为 **Clean Product Rewrite**，不是继续 patch 旧 Wealth IA。
2. 新增 **Value Router**：No Value, No Premium Compute。
3. 新增 **Sparse Activation / Semantic Agent Connectome**。
4. Skill 正式定义为 **Skill Circuit**。
5. 新增 **Living Brain feedback / Brain Trace Replay**，但不增加主导航复杂度。
6. 新增 **Compute ROI / Token Productivity**。
7. Energy 定价明确与真实 compute cost 锚定，并与 3X price volatility 解耦。
8. 新增 **Skill Arena** 和 bounded learning。
9. 明确 MaleCNS 仅进入 **3X Labs**，不进入真钱核心决策。
10. 补齐 AI Studio 分阶段 implementation manifest、DB schema、OpenAPI、event catalog、feature flags、mock fixture、release checklist。
